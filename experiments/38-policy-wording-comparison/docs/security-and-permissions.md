# Security and permissions

The control is [agent-manifest.yaml](../agent-manifest.yaml). `permissions.yaml` is the same file. Autonomy is A0. Writes are disabled. Sends are disabled. The wording specialist validates every interpretation.

## What a run may read

The pack the specialist supplies, the as-of date, and the pinned notes in `src/sources.py`. The Python starter does not persist the text. A pack that is not marked synthetic is refused, and the refusal does not echo the body.

Experiment 12 inventories the text files and calls Experiment 08 for UK identifiers. A file with a deterministic identifier finding is not quoted. `output_is_anonymised` stays false. Experiment 33 checks that the quote is inside the cited lines. Experiment 29 checks numbers and ISO dates. None of those calls uses the network.

## What a run must not do

It must not interpret favourability, recommend buy, sell, or renew, draft an endorsement, contact a broker, write a policy administration system, or make a coverage decision. Those functions raise. The command flags exit without a draft.

## Human approval

1. The wording specialist validates every row, including each not stated cell.
2. The wording specialist re-opens a stale pinned page before relying on the legal note.
3. Favourability, any recommendation, any endorsement, any broker message, and any policy-administration write stay outside this agent.
4. A data protection officer confirms a lawful basis before any live wording is processed. This manifest does not choose an Article 6 basis.

`record_specialist_review` can record that a person with the role "Wording specialist" looked. The agent cannot call it. Acknowledgement is not a recommendation. `downstream_use_permitted` stays false.

## Tenant controls that are named and not configured here

An earlier experiment recorded that user prompt attack detection is on by default and document attack detection is off by default, and that Spotlighting is preview. This folder does not call them. Shields would not replace the missing send and write tools.

Power Platform DLP, Purview, and Application Insights were not opened for this experiment. Unverified. Key Vault is named because a later secret would go there. This starter has no secret.

## Logging

This starter writes no log. Before live use, log who ran it, the pack id, the as-of date, and whether an injection pattern was detected. Do not put the wording text in an application trace.

## ATRS

This starter does not submit a record. The manifest's `atrs_mapping` block is a pointer. Experiment 03 drafts a pack. It does not approve one.
