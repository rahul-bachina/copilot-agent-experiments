# Microsoft Foundry

A path for a team that wants a short narrative around the draft JSON. It is not a deployed project. No Foundry resource is created by this repository. The name is Microsoft Foundry.

The draft in `src/investigate.py` remains the system of record. A model does not set `mlro_decision`, file a report, or draft customer text. Experiment 10 remains the Travel Rule triage. Experiment 16 remains the KYC checklist. Experiment 08 remains the identifier gateway. A model does not replace any of them.

## What was not called

This starter makes no network call and does not query a chain. Fabric is the catalogue place a firm might later hold an alert export. This folder does not connect to a Fabric workspace.

## What a model may do, if a team adds a narrative

- Turn the draft JSON into a short brief for the nominated officer, using only fields that are already in the JSON.
- Point at `prompt_injection`, `sources_stale`, `alert_context_stale`, and any future-dated hop in the first paragraph.
- Repeat that `mlro_decision` is null, that `customer_facing.text` is null, and that the nested gateway output is not anonymised.

## What the model must not do

- Set `mlro_decision`, `sar_filed`, `nca_contacted`, or `daml_requested`.
- File, or describe the draft as filed or submitted.
- Draft any customer-facing sentence about the suspicion, the disclosure, or an investigation.
- Say "we suspect" or that reasonable grounds are made out.
- Assign a glossary code, or invent a hop, a price, or a sterling conversion.
- Treat a supplied label or a sanctions or PEP marker as a determination.
- Apply the MARC on-chain sentence on the 30 June 2026 overview to this AML alert.
- Clear a stale flag because the case says the alert is current.
- Describe the analyst note as anonymised, or reconstruct an omitted address.

Prompt shields in Microsoft Foundry are named in the security note as a tenant control. The product page was not opened for this experiment. Availability in a given tenant is unverified here.

## Region

If a narrative is added later, run it in UK South or UK West and confirm the data-use terms at the time. This folder does not create that resource.
