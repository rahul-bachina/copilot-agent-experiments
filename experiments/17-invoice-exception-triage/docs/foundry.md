# Microsoft Foundry

A path for a team that wants a short narrative around the triage JSON. It is not a deployed project. No Foundry resource is created by this repository. The name is Microsoft Foundry.

The triage in `src/triage.py` remains the system of record. A model does not set an exception class, a pence difference, a stale flag, the resolution code, or the prompt-payment arithmetic. Experiment 12 remains the inventory. Experiment 08 remains the identifier gateway. A model does not replace either.

The catalogue row names AI Builder beside Copilot Studio and Power Platform. This starter does not call AI Builder. A product page for a prebuilt invoice model was not opened for this revision, so no AI Builder capability is claimed. **Unverified here.**

## What was not called

This starter makes no network call. Azure Document Intelligence and Content Understanding were not re-opened for this experiment. Experiment 12's note records a reading of those pages on 27 October 2026 and says they are not called. This experiment relies on that boundary: a file that Experiment 12 marks `not_read` stays a gap. Treat any detail of those product pages that is not repeated here as unverified for this folder.

## What a model may do, if a team adds a narrative

- Turn the triage JSON into a short brief for the AP reviewer, using only fields that are already in the JSON.
- Point at `prompt_injection`, `bank_detail_change`, `sources_stale`, and `prompt_payment.payment_instructed` in the first paragraph.
- Repeat that `invoice_paid` is false and that the nested gateway output is not anonymised.

## What the model must not do

- Invent an exception class, a hash, a pence difference, or a payment date.
- Set `invoice_posted`, `invoice_paid`, `invoice_held`, or `supplier_bank_details_changed`.
- Decide that the invoice is valid, undisputed, or a duplicate.
- Decide that input tax can be recovered.
- Clear a stale date because the file says the invoice is current.
- Describe the text as anonymised, or reconstruct a sort code or account number.
- Post, approve, hold, or pay the invoice, or change a supplier bank record.

Prompt shields in Microsoft Foundry are named in the security note as a tenant control. The product page was not opened for this experiment. Availability in a given tenant is unverified here.
