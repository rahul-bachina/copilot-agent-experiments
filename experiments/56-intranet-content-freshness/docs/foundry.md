# Microsoft Foundry

An optional narrative can sit beside the report. It may use only fields already in the JSON. It must not add a finding, lower a marking, or set `human_approval`.

No Microsoft Foundry resource is deployed by this starter. Prompt shields, Key Vault, and Application Insights were not opened on 16 November 2026. Treat that product behaviour as unverified.

If an organisation later deploys a model, the manifest says the region should be UK South or UK West. This repository cannot enforce that. The model is not given a tool that edits a page, calls Planner, or messages staff.

`model_called` stays false in the Python core. A narrative is not a substitute for `record_approval`.
