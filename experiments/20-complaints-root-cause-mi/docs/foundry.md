# Microsoft Foundry

A path for a team that wants a short narrative around the draft JSON. It is not a deployed project. No Foundry resource is created by this repository. The name is Microsoft Foundry.

The draft in `src/report.py` remains the system of record. A model does not assign a theme, invent a figure, or decide that a return is complete. Experiment 02 `analyse()` and Experiment 08 `propose()` remain the classifiers and the identifier gateway. A model does not replace them, and a model does not call the text anonymised.

## What was not called

This starter makes no network call. Prompt shields in Microsoft Foundry are named in the security note as a tenant control. The product page was not opened on 29 October 2026. Availability in a given tenant is unverified here.

## What a model may do, if a team adds a narrative

- Turn the draft JSON into a short brief for the complaints owner, using only fields that are already in the JSON.
- Point at `prompt_injection`, `sources_stale`, and any cluster whose `validated` field is false, in the first paragraph.
- Repeat that `is_final_regulatory_return` is false, that the three compliance fields are null, and that the nested gateway output is not anonymised.

## What the model must not do

- Invent a theme, a count, a rate, a trend, or a redress figure.
- Set `clusters_validated`, `narrative_validated`, `submitted`, `published`, or `sent`.
- Set `complying_with_consumer_duty`, `code_compliant`, or `ofgem_return_complete`.
- Confirm compliance with the Consumer Duty, the Complaint Handling Code, or an Ofgem return.
- Clear a stale flag because a record says the sources are current.
- Move an out-of-period record into a cluster.
- Describe the text as anonymised, or reconstruct a redacted identifier.
- Validate the clusters or the narrative, publish the report, or send a return.

## Region

If a narrative is added later, run it in UK South or UK West and confirm the data-use terms at the time. This folder does not create that resource.
