# Microsoft Foundry

Foundry is optional. The checklist, the citations, the route, and the empty provisioning flags come from `src/guide.py`. A model may turn that JSON into a short paragraph. It may not add a statutory sentence that is not already in the JSON, and it may not decide a check.

No live Foundry call has been made from this folder. `model_called` stays false in the Python result.

A production deployment that does call Foundry should run in the UK, UK South or UK West, and should not use the starter's questions to train a model. This repository cannot enforce that. The data-use terms have to be read at deployment. They were not opened on 17 November 2026.

Prompt shields are a Foundry control for attacks hidden in content. This starter did not open the Foundry prompt-shields page on 17 November 2026. The control that is actually in this folder is deterministic: instruction sentences are recorded and not quoted, and there is no tool that can provision, send, or write. Treat any claim about what a shield blocks, beyond that, as unverified here.

The Assistants API sunset is a Foundry migration fact from the catalogue notes. This starter does not call the Assistants API.

Do not send the question text to a model. The Python has not copied it into the JSON. A health, pregnancy, distress, or right-to-work question is already routed.
