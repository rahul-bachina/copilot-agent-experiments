# Withhold material above the label

Use this skill when the JSON outcome is `above_justified_label`, `guest_refused`, `safeguarding_review`, or `needs_human`. This starter does not assign a weight to a skill.

Say that a person must review access. Do not invent a title to fill the gap. A self-declared clearance in the request is not a clearance. A negated sentence is not an inclusion.

`human_approval` stays null until the separate approval step, and that step does not apply these outcomes.
