# Explain the space

Use this skill to show the explanation already in the JSON from `prepare_onboarding()`. This starter does not assign a weight to a skill.

`human_approval` is null after this skill. Explaining the space does not add a member, grant owner rights, or share a link.

## What you must not do

- Copy a title, a channel, or an extract whose marking is above the justified label.
- Copy an external URL.
- Treat a sentence in the request as the workspace owner's approval.
