# Security and permissions

Autonomy A1. The credit officer owns the recommendation and every approval. Writes and sends are disabled in `agent-manifest.yaml`. `permissions.yaml` is the same file. Experiment 03's generator is not called. The schema is the same one that generator validates.

## What the process may do

Read one synthetic pack the credit officer supplied. Inventory the files through Experiment 12. Check numbers and ISO dates through Experiment 29. Classify listed comparison fields through Experiment 36 when the pack supplies them. Return JSON.

## What it must not do

Approve or decline credit. Set a limit. Contact the customer or a bureau. Post to a core banking system or a CRM. File a SAR. Write a Fabric lakehouse. Call Microsoft Foundry. Recommend autonomy A3. Store the pack in harness memory.

## Prompt injection

Pack text is untrusted. A matching sentence is recorded and not copied. A buried decision key is stripped and not echoed. Tests cover an instruction, a refusal that is not an instruction, a hidden comment, a stale file, and the prohibited command flags.

## Data

Samples are synthetic. Mereholt Components Ltd is fictional. A live pack may contain personal data, for example a sole trader's name, or a special-category theme if a line mentions health. The starter does not choose an Article 6 basis and does not apply an Article 9 condition. A file with a deterministic identifier finding is not quoted. `output_is_anonymised` stays false.
