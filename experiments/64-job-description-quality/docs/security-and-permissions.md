# Security and permissions

Manifest `exp-64-job-description-quality`, version 0.1.0. Autonomy **A0**. Writes disabled. Sends disabled. `permissions.yaml` is the same file as `agent-manifest.yaml`.

The recruiter accepts or rejects each suggestion. The HR partner sees a route. The recruiter writes the final wording. The agent does not publish, post, or send, and it does not score anyone.

## Identity and access

The directory in the fixture is the source of the role and the clearance. A sentence in the draft is not. A guest stays a guest. An unreadable clearance is not replaced with OFFICIAL.

Entra Agent ID, Conditional Access for agents, and a configured Power Platform DLP policy were not opened on 18 November 2026. Treat that product behaviour as unverified. A production deployment should use the organisation's existing identity and DLP controls. This starter does not configure them.

## Data

The draft may contain personal data if someone pastes it. Experiment 08 proposes UK identifier redactions. This core also masks phone numbers, email addresses, dates of birth, postal addresses, and names introduced with "my name is" or a title. Counts do not store the values. The output is not described as anonymised.

A SECRET cover is read from the page even when the metadata says OFFICIAL. The higher marking is kept. Text above the directory clearance is not copied. A legal hold and every retention label are kept when the wording is recorded. A mandated statement that was in the draft has to remain in the recruiter's text.

Microsoft Purview, Key Vault, and Application Insights were not opened on 18 November 2026. Treat that product behaviour as unverified. Do not put the draft body in an application trace.

## Approval

An approval is a separate object.

- The approver reference has to match the synthetic directory and the role that step requires.
- A suggestion decision has to carry the draft hash and that suggestion's hash.
- The final wording has to carry the hash of the exact text.
- A string is not coerced to the boolean true.
- Approval words inside the draft are ignored.

## Model note

Microsoft Foundry is optional and unused in this repository. Prompt shields were not opened. A note, if one is added later, may only use fields already in the JSON.

## Switch it off

Turn the Copilot Studio agent off, or revoke the credential used for an optional note. Times are the platform's, not a measured drill. Contacts in the manifest are placeholders on ashcombe.example.gov.uk. Ashcombe Borough Council is invented.
