# Microsoft Foundry

Microsoft Foundry is an optional short note written from the JSON that `propose_register()` already returned. Quotes, hashes, applicability candidates, and the approval step stay in the Python core.

No Foundry resource is deployed from this folder. The tool in the manifest is read-only and its output still needs a person. It cannot stage a change and it cannot send.

A production deployment, if an organisation adds one, should use a UK region. This repository cannot enforce that. Prompt shields were not opened on 23 November 2026. Treat that product behaviour as unverified.

The product name is Microsoft Foundry.
