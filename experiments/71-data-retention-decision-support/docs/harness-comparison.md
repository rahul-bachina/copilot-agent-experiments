# Which harness

Opened on 23 November 2026: [Harnesses in Copilot Studio](https://learn.microsoft.com/en-us/microsoft-copilot-studio/harnesses-overview).

The page names three harnesses.

- **Standard harness.** Rule-based agents and agent flows. The maker defines the topics, prompts, and paths. The page says this harness follows those rules. It points to licensing for agents powered by the standard harness. It does not state a price on the overview.
- **Microsoft Copilot harness.** Reasoning-heavy, multi-step work. The page describes skills, memory, file creation and editing for Word, Excel, PowerPoint, and PDF, and a sandbox governed by Copilot Studio. The prose says agents and workflows on this harness use Copilot Credits. It states no price. No "last updated" line was in the extract. That date is unverified.
- **Customer Conversation harness.** Voice and chat for customers, with escalation to a person. This experiment does not use it. Retention advice is not a customer conversation.

The page does not use the words "GitHub Copilot harness". It does not say the harness is not the GitHub Copilot service. Older wording to that effect is unverified against the page opened on this date.

The common brief asks for a Copilot Studio GitHub Copilot harness. This folder packages that request as the Microsoft Copilot harness: skills under `skills/`, the same approval gates, and the same Python core. It is a packaging choice. It is not a claim that the Learn page uses that name.

Catalogue row L007 names Microsoft 365 and Copilot Studio first. Microsoft 365, in this folder, is the place a records inventory might live in a tenant. This starter does not call Microsoft Graph. Power Platform is not a stack code on this row. The Foundry note is still here because a team may want a short narrative beside the JSON.

Both harnesses stop before disposal. `record_advice_seen` is the only seen step, and it does not change a record. Building the Microsoft Copilot harness in a tenant consumes Copilot Credits. This file does not quote a price.
