# Microsoft Foundry

Optional. No Foundry resource is deployed from this folder.

A short note may be written from the JSON `advise_retention()` already returned. The note may quote the line id, the indicative date, and the questions. It may not add a disposal, a transfer, or a finding that Article 5(1)(e) was met.

The advice hash, the pinned line, the legal hold, and the seen step stay in the Python core. A Foundry note that disagrees with the JSON is discarded.

Prompt shields, if a tenant enables them, were not opened on 23 November 2026. Treat that product behaviour as unverified. The deterministic checks in `src/advice.py` still run: pinned sources, negation, the hash, and the prohibited functions.

Use a UK region if a team deploys this. This repository cannot enforce the region.

The retired product name is not used.
