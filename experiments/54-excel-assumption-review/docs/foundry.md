# Microsoft Foundry

No Foundry resource is deployed by this starter. `model_called` is false on every result the Python produces.

If an organisation later connects a model, the model may only turn the JSON into a short brief. The inventory, the hard-coded literals, the formula shapes, the sensitivity ranking, and the empty `findings_accepted` stay in `src/review.py`. The model must not add a benchmark, a "should be" figure, or a judgement that an assumption is right or wrong.

The workbook text must not be used to train a model. A production deployment should run in UK South or UK West. This repository cannot enforce that. Microsoft Foundry prompt shields were not opened on 13 November 2026 and are unverified here.
