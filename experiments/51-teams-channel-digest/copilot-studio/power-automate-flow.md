# Power Automate

There is no flow in this starter.

A later flow, if a tenant adds one, may call `src/digest.py` and return JSON to the topic. It must not include an action that posts, replies, reacts, mentions, or forwards. The Teams connector's action list was not opened on 12 November 2026. Those action names are unverified. The prohibition is the effect.

The flow must not pass message text into the confirmation. The confirmation is a separate object the user submits.

Writes and sends stay disabled in `agent-manifest.yaml` until that file is changed first. This starter does not change it.
