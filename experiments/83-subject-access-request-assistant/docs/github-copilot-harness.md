# Microsoft Copilot harness

The skills in `skills/` are the harness the common brief calls the GitHub Copilot harness. The harness overview at `https://learn.microsoft.com/en-us/microsoft-copilot-studio/harnesses-overview` was opened on 27 November 2026. The page uses the name Microsoft Copilot harness. It does not use the words GitHub Copilot harness.

The page describes a reasoning-heavy multi-step harness with skills, memory, and files, and it says that harness retries and finds alternative paths automatically. This starter must not enable that retry. There is no send to retry.

The page also describes a Customer Conversation harness for voice and chat. This starter is not that harness. The page stated no price for either harness. The standard-harness price page was not opened, so this starter does not state a price.

The sentence that this harness is not the GitHub Copilot service was not on the page that was opened. That sentence is unverified.

## Skills

| Skill | When |
|---|---|
| `scope-subject-access-request` | The officer has a synthetic request and a records export |
| `record-route-seen` | The draft outcome is `route_to_human` and the officer has seen that route for this hash |
| `record-disclosure-approval` | The officer is recording accept or reject for every redaction and exemption on this hash |

Each `SKILL.md` description is one line and says when to use the skill. The files do not list phrases for selection and do not assign weights.
