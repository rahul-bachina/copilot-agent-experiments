# Standard harness

This folder is a topic guide for Copilot Studio. It is not an importable solution, and it does not create a Power Platform environment.

The topic calls `scope()` in `src/sar.py`, then, when the officer is ready, `record_route_seen()` and `record_disclosure_approval()`. The system prompt is `system-prompt.md`. The flow note is `power-automate-flow.md`.

There is no connector that sends email, writes a case system, or deletes a record. If a topic is later given such a connector, that is outside this starter.

The other harness is the skills in `skills/`. See `docs/harness-comparison.md`. The harness overview was opened on 27 November 2026. It names a Microsoft Copilot harness. It does not name a GitHub Copilot harness. It says that harness retries. This starter does not enable that.
