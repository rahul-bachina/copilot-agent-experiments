# Microsoft Foundry

Foundry is optional. The citation, the version, the empty entitlement, and the route come from `src/answer.py`. A model may turn that JSON into a short paragraph. It may not add a day count, a case outcome, or a statutory sentence that is not already in the JSON.

No live Foundry call has been made from this folder. `model_called` stays false in the Python result.

A production deployment that does call Foundry should run in the UK, UK South or UK West, and should not use the employer's questions to train a model. This repository cannot enforce that. The data-use terms have to be read at deployment. They were not re-opened on 16 November 2026.

Prompt shields are a Foundry control for attacks hidden in content. This starter did not re-open the Foundry prompt-shields page on 16 November 2026. The control that is actually in this folder is deterministic: instruction sentences are recorded and not quoted, and there is no tool that can decide, send, or write. Treat any claim about what a shield blocks, beyond that, as unverified here.

The Assistants API sunset is a Foundry migration fact from the catalogue notes. This starter does not call the Assistants API.

Do not send the question text to a model if it may contain health, pregnancy, or a safeguarding line. The Python has already routed those questions and has not copied the question into the JSON.
