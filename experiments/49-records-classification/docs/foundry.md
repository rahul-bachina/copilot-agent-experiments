# Microsoft Foundry

A path for a team that wants a short narrative beside the classification JSON. It is not a deployed project. No Foundry resource is created by this repository. This starter makes no Foundry call.

If a team adds one later, the model may only restate fields that are already in the JSON: the category id, the retention entry, the disposal action, the marking suggestion, the confidence, the queue reasons, and the fact that `human_approval` was null. It must not invent a statutory period, a public-record decision, or a Purview label.

Prompt shields are a control Microsoft documents for generative deployments. The product page was not opened on 11 November 2026. Treat the current control name as unverified. A filter is not a substitute for having no delete tool.

A production deployment should use a UK region, UK South or UK West. This repository cannot enforce that. The manifest says the same.

The Assistants API is not used. This note does not claim a current retirement date for it. That page was not opened for this experiment.
