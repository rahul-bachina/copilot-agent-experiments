# Microsoft Foundry

The queue, the priority, the reason, the confidence band, and the empty approval are computed in `src/routing.py`. A Microsoft Foundry model is not required to run this starter, and none is called by the tests.

If an organisation later wants a short brief, the model may narrate fields that are already in the JSON. It must not add a queue, a date, or a duty-met statement. Prompt shields, if the organisation enables them, are a control on that narration. The product page was not opened on 9 November 2026. Treat the current control name as unverified here. A filter is not a substitute for having no reroute tool.

Experiment 01 can call a Foundry model for triage. This experiment does not. It reuses the classification names only.

Deploy in UK South or UK West if a model is used. This repository cannot enforce the region. Do not train on resident cases. No Foundry resource is created in this folder.

The retired product name is not used. Say Microsoft Foundry.
