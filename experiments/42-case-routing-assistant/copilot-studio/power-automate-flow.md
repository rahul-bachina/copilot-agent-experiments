# Flow shape

A Power Automate flow, if someone builds one, has two actions and then stops.

1. Run the Python proposal for the pasted case and the typed as-of date. Return the JSON.
2. Optionally run `record_review` when a separate review object is posted. Return that JSON.

Do not add an action that updates a Dynamics 365 queue, closes a case, sends mail, or writes a rule row. The catalogue stack names Dynamics 365 and Power Platform. This folder does not connect either. Product click-paths were not opened on 9 November 2026.

The flow runs as the signed-in maker or as a service account the organisation chooses. This starter does not register an agent identity. Entra Agent ID was not opened for this experiment. That product note is unverified here.

DLP should block any case-system, mail, or telephony connector added later. No policy is configured in this repository.
