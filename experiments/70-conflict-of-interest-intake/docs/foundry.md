# Microsoft Foundry

A path for a team that wants a short narrative beside the declaration JSON. It is not a deployed project. No Foundry resource is created by this repository. This starter makes no Foundry call.

The narrative may use only fields already in the JSON. It must not set `conflict_exists`, `person_cleared`, `supplier_excluded`, or `sent`. It must not say the draft was anonymised. It must not say a conflicts assessment was prepared.

Prompt shields in Microsoft Foundry were not opened on 20 November 2026. Treat that product behaviour as unverified. The control that ignores instructions in the declaration is the Python core.

A production deployment that did call Foundry should use a UK region. This repository cannot enforce that. The Assistants API was not used. Its retirement is not re-checked here.
