# Microsoft Foundry

Microsoft Foundry is optional. The explanation, the version choice, the statutory pins, the empty entitlement, and the empty pay fields are produced by `src/explain.py`. A Foundry narration, if a deployment adds one, may only restate fields that are already in that JSON.

This starter does not deploy a Foundry project. No model was called for the smoke test. `eval/smoke_report.json` is a deterministic smoke test, not a model score.

Prompt shields, content filters, and a UK region are controls a deployment would confirm. The Foundry prompt-shields page was not opened on 18 November 2026. Their current behaviour is unverified here. This file does not state that a shield caught an instruction. The deterministic core records instructions and does not follow them, whether or not a shield is configured.

A key, if one is used for a narration, belongs in a secret store the employer already operates. It is not in this folder.
