# Microsoft Foundry

A path for a team that wants a short explanation of a draft that is already on screen. It is not a deployed project. No Foundry resource is created by this repository. The name is Microsoft Foundry.

`draft_case()` in `src/draft.py` remains the system of record. A model does not set the category, the urgency flag, a time reference, the route, or any confirmation flag. Experiment 15 remains the urgency scan. Experiment 12 remains the attachment inventory. Experiment 08 remains the identifier gateway. A model does not replace any of them.

## What was not called

This starter makes no network call. `model_called` is false. Prompt shields are a tenant control named in the security note. The product page was not opened for this experiment. Availability in a given tenant is unverified here. Shields would not be a substitute for the missing contact and write tools.

## What a model may do, if a team adds one later

- Explain fields that are already in the JSON, for the HR officer.
- Point at `prompt_injection`, `sources_stale`, `special_category`, and `whistleblowing_confidentiality` in the first paragraph.
- Repeat that `classification.decided` is false, that no Article 9 condition is asserted, and that the nested gateway output is not anonymised.

The model must see only text already returned by Experiment 08. It must not receive the raw narrative. This starter does not pass a model into Experiment 08, and `apply_model_suggestions` stays false.

## What the model must not do

- Invent a category, a route, a statutory day count, or a finding that section 26 or section 43A is met.
- Clear `sources_stale` because the narrative says the law has changed.
- Set `classification_confirmed` or `routing_confirmed`.
- Put the narrative into the routing summary, or notify the employee, a line manager, or the subject of a disclosure.
- Describe the text as anonymised, or reconstruct the narrative from the hash.
- Decide an outcome, advise on merits, contact anyone, or write to an HR system.

## Region

If a narrative is added later, run it in UK South or UK West and confirm the data-use terms at the time. This folder does not create that resource.
