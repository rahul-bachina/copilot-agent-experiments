# Microsoft Foundry

This evaluator does not create a Microsoft Foundry agent, a project, or a deployment. No Foundry resource was created while this folder was written. A live Foundry run has not been done.

The catalogue row for G004 is Copilot Studio on the GitHub Copilot harness. Foundry is an optional later host for the same JSON, if an organisation already runs Agent Service and wants the routing report beside other evaluations. This folder does not recommend that move. Experiment 14 can draft options when a use case is supplied. `platform_selected` stays null.

## What Experiment 14 stored

Experiment 14 opened Microsoft Learn pages on 27 October 2026. Experiment 26 did not re-open them.

The Agent Service overview, as stored by Experiment 14, describes identity with Microsoft Entra, role-based access, private networking, and Application Insights. Those are not configured here. A UK region list was not on the overview Experiment 14 opened. UK region availability for a later deployment is unverified.

Agent optimizer and voice were marked preview on the page Experiment 14 opened. They are not selected here.

## Prompt Shields

The Prompt Shields page in Microsoft Foundry was opened by Experiment 14. User prompt attack detection is described as on by default. Document attack detection is described as off by default. Tool-response scanning and Spotlighting are marked preview. The page says the service is Azure AI Content Safety. This evaluator does not call Prompt Shields. A local pattern match is not a shield result, and a shield result would not validate the routing tests.

## What would still be true in a later host

The Python report would still be the route. `maintainer_validated` would still start false. A person would still validate the tests before a skill file changed. The host would not be a reason to enable a write or a send.
