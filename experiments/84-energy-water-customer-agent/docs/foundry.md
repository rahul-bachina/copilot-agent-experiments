# Microsoft Foundry

Catalogue row UK12 names Microsoft Foundry as an optional part of the stack. This folder does not deploy a Foundry resource. The answer, the proposal, the hash, and the confirmation are computed in `src/customer.py`. A model is not called. `model_called` stays false.

If an organisation later asks a model to turn the JSON into a short note, the note may use only fields already on the result. It must not add a tariff, a balance, a complaint outcome, or a confirmation. The hash and `confirmation_recorded` stay in the Python core.

Microsoft Foundry prompt shields were not opened on 27 November 2026. Treat that product behaviour as unverified. Do not describe a shield as configured here.

Say Microsoft Foundry. Do not use the retired product name.
