# Microsoft Foundry

The catalogue stack for this agent is Dynamics 365 and Microsoft Fabric. Microsoft Foundry is an optional narrative around the JSON, not the system of record.

`src/gaps.py` does not call a model and does not call the network. Gap ids, freshness, conflicts, the screens, and the empty approval are computed in Python. A later brief may restate fields that are already in the JSON. It must not add an article body, choose a side of a conflict, or publish.

If an organisation deploys that narrative, the manifest says the deployment should use a UK region and should not be trained on customer text. This repository cannot enforce that. The region control was not checked in a portal on 10 November 2026.

Microsoft documents prompt shields as a control on generative deployments. Confirm the current control name in the resource you use. Nothing in this starter enables one. **Unverified here:** the portal label on 10 November 2026. That product page was not opened.

A live Microsoft Foundry run has not been done. `eval/smoke_report.json` is a deterministic smoke test of the Python. It is not a model score.
