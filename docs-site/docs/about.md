# About

Rahul Bachina is a UK solution architect. The experiments in this repository are on Power Platform, Copilot Studio, Microsoft Foundry, Azure AI, and GitHub Copilot.

The catalogue is published so UK government bodies and FCA-regulated firms can see practical starting points, including what an agent must not do. It is maintained by one person. It is not a product, a consultancy offer, or a statement that any organisation is compliant.

The source of truth is the [GitHub repository](https://github.com/rahul-bachina/copilot-agent-experiments). These pages are the briefing.

People extending the catalogue can follow [Adding a page](adding-an-experiment.md).
